# Zulip 定制版 / Zulip Customized

## 中文

本仓库是基于 [Zulip](https://github.com/zulip/zulip) 13.2 的二次开发版本，定制内容都在
`custom/13.x` 分支上。

- [开发规范](https://github.com/ErduBis/zulip/blob/custom/13.x/custom/zh/DEVELOPMENT.md)：环境、角色分工、工作方式、代码要求、协作规则
- [决策记录](https://github.com/ErduBis/zulip/blob/custom/13.x/custom/zh/DECISIONS.md)
- [定制清单](https://github.com/ErduBis/zulip/blob/custom/13.x/custom/zh/CUSTOMIZATIONS.md)：为定制功能对 Zulip 原有代码的修改
- [开发指南](https://github.com/ErduBis/zulip/tree/custom/13.x/custom/zh/guides)：按角色分篇的 Zulip 开发知识

许可证：Apache License 2.0，见 [LICENSE](https://github.com/ErduBis/zulip/blob/custom/13.x/LICENSE) 和 [NOTICE](https://github.com/ErduBis/zulip/blob/custom/13.x/NOTICE)。

## English

This repository is a customized version of [Zulip](https://github.com/zulip/zulip) 13.2. All
customizations live on the `custom/13.x` branch.

- [Development guide](https://github.com/ErduBis/zulip/blob/custom/13.x/custom/en/DEVELOPMENT.md): environment, roles, workflow, code
  requirements, collaboration rules
- [Decision log](https://github.com/ErduBis/zulip/blob/custom/13.x/custom/en/DECISIONS.md)
- [Customization inventory](https://github.com/ErduBis/zulip/blob/custom/13.x/custom/en/CUSTOMIZATIONS.md): changes to Zulip's original code for our customizations
- [Development guides](https://github.com/ErduBis/zulip/tree/custom/13.x/custom/en/guides): Zulip development knowledge, one guide per role
