# 截图开发服务器

以测试用户身份登录 `http://localhost:9991`，打开指定页面并截图，然后用 Read 工具查看截图。

```bash
cd ~/zulip
node .claude/skills/screenshot-dev/screenshot.mjs [选项]
```

| 选项                  | 默认                             | 说明                                                              |
| --------------------- | -------------------------------- | ----------------------------------------------------------------- |
| `--user <邮箱>`       | `sunwukong@zulip.com`            | 登录的测试用户（devlogin 页上的任意一个）                         |
| `--path <路径>`       | `/`                              | 登录后打开的地址，例如 `/#channels/3/devel`、`/#settings/profile` |
| `--out <文件>`        | `/tmp/screenshot-dev-<时间>.png` | 截图保存位置；脚本最后一行输出这个路径                            |
| `--lang <语言>`       | 用户原设置                       | 临时切换界面语言，中文用 `zh-hans`                                |
| `--dark`              | 否                               | 临时切换为深色主题                                                |
| `--width/--height`    | `1280` / `800`                   | 窗口大小；手机宽度用 `--width 480`                                |
| `--wait-for <选择器>` | 无                               | 截图前等这个元素出现                                              |
| `--element <选择器>`  | 无                               | 只截这个元素                                                      |
| `--full-page`         | 否                               | 截整页                                                            |

`--lang` 和 `--dark` 只在截图期间生效，截图后把该用户的语言和主题恢复成原来的设置。

## 注意

- 开发服务器要在运行（见开发规范「环境」一节）。
- 9991 用的是和用户共享的开发数据库。这个脚本只登录和浏览，除了上面两个临时设置不改数据；
  需要点按钮、发消息、改设置来验证时，用 `/visual-test`（独立测试库）。
- 需要多步操作才能到达的界面，把 `screenshot.mjs` 复制到 `/tmp/` 改写，不要改仓库里的这份。
- 对比改动前后时，分别截图后一起查看；对齐、间距拿不准时用 `--element` 截局部放大看。
